How scoring works

The AQ-10 is a shortened version of the 50 item Autism Spectrum Quotient. Cambridge’s Autism Research Centre published it in 2012 after testing it on 1,000 autistic adults and 3,000 controls.

One point per statement

Each statement scores at most one point. For four of them, agreeing scores the point. For the other six, disagreeing does. “Slightly” and “definitely” count the same.

The referral level

NICE guideline CG142 advises clinicians to offer a specialist assessment when an adult scores {{ threshold }} or more. It’s a level for asking further questions, and many people above it turn out not to be autistic.

About the machine learning model

The first version of this project trained a random forest to predict autism from the ten answers. In the UCI Autism Screening Adult dataset, though, the label itself comes from the AQ-10 total: anyone scoring above 6 is marked positive. A model trained on the ten answers just relearns that sum, so its near perfect accuracy tells you nothing new.

This version scores the questionnaire directly. The training script in the repository still runs the comparison, printing the plain sum rule next to logistic regression and a random forest, so you can see the leak for yourself.
